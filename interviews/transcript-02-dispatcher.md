# Interview — Dispatcher
**Subject:** Keisha, Dispatch Coordinator, 3 years
**Context:** Manages 12 field technicians across 3 regions

---

"I need to know where my techs are at any given time. Right now I'm texting them. Which is ridiculous. When a client calls and asks where the technician is, I'm guessing. The check-in system was supposed to fix this but half of them aren't using it. Marcus told me it's too slow. I can see that — when I used it to test it took me about 45 seconds just to check in. That's not going to work when you're between jobs."

**Pain points identified:**
- Real-time location visibility needed
- Low adoption (check-in being skipped)
- 45-second check-in is unacceptable
- Dependent on techs doing the right thing

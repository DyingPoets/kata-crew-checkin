# Field Crew Check-In — Current Wireframe

## Screen 1: App Home
- Company logo header
- Navigation menu (hamburger)
- "Welcome, [name]" greeting
- Four menu items: Check In, Check Out, My Jobs Today, Settings
- Footer with version number

## Screen 2: Check In
- "Check In" header
- Text field: "Enter site code or search by name"
- Search results list (up to 10 results)
- Manual GPS coordinates option (toggle)
- "Confirm Check-In" button (grey until site selected)
- Cancel link

## Screen 3: Site Confirmation
- "You are checking in to:" header
- Site name and address
- Current time
- Photo capture option (optional)
- Notes field (optional, 500 chars)
- "Submit Check-In" button
- "Go Back" link

## Screen 4: Success
- Checkmark icon
- "Check-in recorded" message
- Timestamp
- "Return to Home" button
